Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Prerequisites

Use Node.js 24+, a supported model and API credit. Windows may require Git Bash. Python is needed only to regenerate the student pages.

node --version
npm --version
02

Install and create your .env file

From presentations enter this application, install locked dependencies, preserve an existing .env and enter your model key privately.

cd .\agent-sdk\lesson30-ui-approvals
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the web application

Keep the terminal open, visit port 3130 and use the navigation buttons to explore the five student pages.

npm start
# http://127.0.0.1:3130
04

Use the actual approval dialog

Choose Approve once and run. Inspect the requested Write and click Approve once. Repeat with Approve with changes, edit the content and inspect reviewed.txt in the independent evidence. For an explicitly scripted CLI demonstration:

npm run sample:env -- approve --decision=approve
npm run sample:env -- change --decision=change
05

Compare remember and refusal responses

Use Remember versus Approve once twice. Inspect actual callback counts, suggestions and session updates. Then try Reject, Suggest and Redirect using the corresponding buttons. Redirect uses the same Query for a separate task.

npm run sample:env -- remember --decision=remember
npm run sample:env -- reject --decision=reject
npm run sample:env -- redirect --decision=redirect
06

Practise terminal approvals and cancellation

Run the terminal example. Enter y to create the disposable test file, then n to deny deletion. The tool request is shown before each decision. Back in the web app compare Pre-approved Write with Cancel while pending.

npm run terminal
# First request: y
# Delete request: n
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3130
# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. Respond to pending approval requests within two minutes. Remember is available only when eligible SDK suggestions exist and suppression is not set. Cancel removes the pending decision without approval. Pre-approved actions do not show the dialog.
